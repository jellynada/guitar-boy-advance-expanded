# Download and play Mission 001

This branch contains the actual tested game files. Main is unchanged.

1. Open `mission001-review.zip` in this folder on GitHub.
2. Click the **Download raw file** button (down-arrow icon) near the upper right.
3. Unzip the downloaded file on your computer.
4. Install mGBA from https://mgba.io/downloads.html.
5. In mGBA choose **File → Load ROM**, then select `guitar-boy-advance-expanded.gba` from the unzipped folder.
6. In mGBA's keyboard/controller settings assign the GBA buttons **L, B, A, R** to keys you find comfortable. Those are the green, red, yellow, blue lanes, from left to right. The song starts automatically.

You can download just `guitar-boy-advance-expanded.gba` the same way if you do not need the instructions and screenshot.

The tested ROM's SHA-256 checksum is:
`277036404c00f38cb335e22b64891c4542c45fd39e11d92fad106ef785a2bee5`

The ROM compiled successfully and ran in mGBA's headless core for about ten emulated minutes with rendering, audio samples and synthetic input. It has not had a human playthrough or listening test.
