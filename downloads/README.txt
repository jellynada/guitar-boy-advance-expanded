Mission 008 - Sunshine of Your Love playtest

1. Extract the ZIP on Windows.
2. Open mGBA and choose File > Load ROM.
3. Open Sunshine-of-Your-Love-Mission-008.gba.
4. Choose Imported Easy Test and press A or Start.

Imported song controls, left to right: Left D-pad / A / B.
S = score, C = combo, X = multiplier.
A miss or wrong input breaks the combo and mutes the guitar.
A successful note restores the guitar.
After the complete recording, A or Start replays; B or Select returns to selection.

This is the existing tested Mission 008 build, containing the supplied Cream
recording and all 395 Easy guitar notes. No gameplay changes were made for
this download. Automated mGBA checks were performed; no manual playtest or
physical Game Boy Advance test was performed by the developer.

Published publicly at the project owner's explicit request for playtesting.
