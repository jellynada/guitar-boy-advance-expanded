Mission 007 — Sunshine of Your Love reactive guitar playtest

1. Extract Sunshine-of-Your-Love-Mission-007.gba from this ZIP.
2. In mGBA on Windows, select File > Load ROM and open that file.
3. Choose Imported Easy Test using Up/Down; press A or Start.
4. Play using GBA Left / A / B mapped to convenient computer keys.
5. Miss a note or press a wrong active button: the selected guitar track fades to silence while backing continues.
6. Hit the next note correctly: guitar returns. Waiting does not restore it.
Start + Select returns to the selector for replay.

This is the existing tested Mission 007 Cream build, unchanged, with the supplied recording and all 395 Easy guitar notes. No gameplay changes or main merge.
