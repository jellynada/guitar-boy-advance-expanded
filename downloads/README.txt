Mission 006 — Sunshine of Your Love playtest

1. Install mGBA from https://mgba.io/downloads.html .
2. Extract Sunshine-of-Your-Love-Mission-006.gba from this ZIP.
3. In mGBA, choose File > Load ROM and open that .gba file.
4. Choose Imported Easy Test with Up/Down; press A or Start.
5. Play with GBA Left / A / B, mapped to your chosen keyboard keys.
Start + Select returns to the selector.

This is the existing tested Mission 006 build, unchanged. It contains the supplied Cream/WaveGroup cover mix and all 395 Easy guitar notes. Source and main have not been changed. This separate download branch was published at the project owner's explicit request for playtesting. No license to third-party music or charts is granted by this download.
