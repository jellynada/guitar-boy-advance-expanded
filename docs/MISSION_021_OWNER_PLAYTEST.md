# Mission 021 owner GBA playtest

Keep the old ROM as a fallback. Use the new M021 ROM on your actual GBA.

- Power on: title,PRESS START,no highway or unwanted music.
- START once enters Main; holding it must not launch multiple screens.
- Check text readability,menu response,Options/Credits and B back.
- PLAY opens Song Select with exactly the packaged song.
- Check each difficulty,physical controls,count-in and full song.
- Hold confirmation A through entry; no accidental note input.
- Pause/Resume preserves position,score,combo and held notes.
- Restart deliberately: same song/difficulty,zero score.
- Quit to Songs:silence,no stuck notes or corrupted graphics.
- Complete each difficulty:Results stays until an action.
- Test Retry,Change Difficulty,Song Select and Main Menu.
- Test quick taps,held directions,opposites and backing through menus.
- Play several consecutive full songs;note crackles,slowdown,flicker or freezes.

Menu UP/DOWN moves once/press;A/START confirms;B backs. START resumes Pause;B cancels its highlight;SELECT quits. Results B goes to Songs. Gameplay lanes are unchanged.

For issues,record ROM filename,difficulty,action and song time. Emulator checks do not replace hardware acceptance. The known strict ordinary-output limitation remains release-blocking.
