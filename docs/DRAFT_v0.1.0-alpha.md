# Draft v0.1.0-alpha notes — not a release announcement

Play Copper Circuit, an original75-second guitar-oriented arcade composition,
on Easy, Medium or Hard. Includes reactive guitar muting/recovery, chords,
sustains, combo scoring, pause/resume, results and replay. Public profile has
no inherited commercial song. Controls and notices travel with the player ZIP.

This candidate is **not release-approved**: strict emulator audio comparison,
pause/repress follow-up and real-GBA owner acceptance remain open. Downloadable
playtest files are separate from any future formal release/tag.
