# RC2 handheld check

RC1's owner report is positive: “It works great! … it truly is a game.”
RC2 still needs its own test. Automated audio-output approval remains blocked.

Download the RC2 `.gba` from the current README, or download its ZIP and choose
Extract All. Open that `.gba` in mGBA or put it on your compatible flash cartridge.
No compiler or command line is required.

- Play Easy, Medium and Hard; you do not need an all-Perfect run.
- Easy LEFT/B/A; Medium LEFT/RIGHT/B/A; Hard LEFT/UP-or-DOWN/RIGHT/B/A.
  Check comfortable diagonals. Either Up or Down is the same Hard lane.
- Try chords, overlapping holds and releasing B while continuing A.
- Miss several notes: guitar should mute, drums/bass continue. Hit a later note
  to restore guitar. Listen for drift, stutter, clicks and the final cutoff.
- START pauses. Wait10seconds, then resume. Try holding continuously, releasing
  while paused, and repressing before resume. A new press after resume can be
  WrongInput if there is no new note to hit; it must not award the old head again.
- Pause near a note, a hold ending and the final song boundary. SELECT while
  paused returns to selection. Finish, replay, switch difficulty and restart
  several times. Try a20-minute session and watch for flicker or missing tails.

If something fails, report console/flash cartridge (or mGBA version), difficulty,
approximate song time and what happened. Your RC1 feedback is preserved; no
comprehensive RC2 acceptance has been inferred from it.
