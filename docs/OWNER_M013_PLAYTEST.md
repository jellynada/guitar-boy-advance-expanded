# Your Mission013 handheld playtest

You do not need to compile anything. Use the encrypted Cream download and the
password supplied in the chat. Download/install 7-Zip only if you do not already
have it. Right-click the ZIP → Show more options → 7-Zip → Extract Here; paste the
password. Ordinary Windows ZIP extraction may not support this AES encryption.

Copy **Guitar-Boy-Advance-M013-Cream-Private.gba** to your flash cartridge using
its usual procedure. In mGBA use File → Load ROM to open that same extracted file.
Confirm **M013 / CREAM / LOCAL** on the selector so you are testing the new build.
The public M013 / SYNTH file is a short artificial test, not the Cream recording.

The imported physical order is now **LEFT, B, A**. B is the middle lane; A is the
right lane. Original Demo stays LEFT, RIGHT, A, B. Menu and results navigation
stays A/Start to begin/replay, B/Select to return, Start+Select to exit play.

Leave these unchecked until you personally test:

- [ ] In INPUT / CHORD TEST, LEFT, B and A light/judge the correct lanes.
- [ ] LEFT+B, LEFT+A, B+A and LEFT+B+A register together when intended.
- [ ] Hold LEFT and tap B; the LEFT hold continues.
- [ ] Hold B+A, then release B while keeping A held; A continues, B releases.
- [ ] Rapid B taps register separately; keeping B held does not produce extra taps.
- [ ] Play the entire Cream song: new physical order feels correct, sustains and
      early release work, a miss mutes guitar and a later hit recovers it while
      backing continues. Watch/listen for any new sync drift or highway flicker.
- [ ] Results show your score; A/Start replays fresh audio and resets score;
      B/Select returns. Start+Select still exits gameplay.
- [ ] Original Demo retains its old LEFT/RIGHT/A/B controls and sound.

You do not need to get an all-Perfect run to approve comfort/usability. The
15,815 reference is an automated395-Perfect/full-hold score, not a first-play goal.
